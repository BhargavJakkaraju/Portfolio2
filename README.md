# Portfolio2

A personal portfolio website built with Next.js, featuring a clean design with a light cream background and smooth scrolling navigation.

## Features

- **Fully Scrollable**: Smooth scrolling between sections
- **Navigation Bar**: Fixed toolbar at the top with links to all sections
- **Sections**:
  - Hero section with personalized greeting
  - About Me
  - Experience
  - Projects
  - Contact Me

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

You can customize the content by editing the component files in the `components` directory:
- `Hero.tsx` - Hero section
- `About.tsx` - About Me section
- `Experience.tsx` - Experience section
- `Projects.tsx` - Projects section
- `Contact.tsx` - Contact Me section

## Design

- Background: Light cream (#faf8f3)
- Text: Black (#000000)
- Accent: Blue (#2563eb) for the name and links
